✦ Technical Architecture

End-to-End Processing Pipeline

Built on a stateless, low-latency stack designed for edge devices.

1

On-Device WebAssembly OCR

Uses Tesseract.js (WASM) directly in the browser. Zero image storage on servers.

2

Regex + Drug Mapping Index

Recognizes 50+ Indian and generic brands (Dolo, Crocin, Pantop, Augmentin, etc.).

3

Clinical Grounding Fetch

Queries OpenFDA Clinical API + Wikipedia REST for contraindications and dosage.

4

Pharmacist Guardrail LLM

Synthesizes clinical data into structured, empathetic Hinglish with safety warnings.

5

Multi-Tier Neural TTS

ElevenLabs Multilingual v2 → Pollinations Audio → Browser SpeechSynthesis failover.
